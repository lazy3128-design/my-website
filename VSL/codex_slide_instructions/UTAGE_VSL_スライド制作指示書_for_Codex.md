# UTAGE VSL スライドデザイン制作指示書（Codex向け）

**バージョン**：v1.0
**作成日**：2026-05-28
**対象**：Codex（または同等のAIコード/画像生成エージェント）
**目的**：UTAGE VSLの全スライド（約220枚）を、大賀VSLの設計思想（5パターン×シーン別）に従い、UTAGEブランドカラーに変換しながら、洗練された見た目で1枚ずつ生成する。

---

## 0. 大原則（最初に必ず読むこと）

1. **出力フォーマット**：PNG画像、サイズ **1920×1080px**（16:9 フルHD）
2. **デザインの参考元**：大賀VSL（172スライド・別資料『大賀VSL_スライド構造分析_v1.xlsx』参照）の**設計思想だけを継承**する
3. **絶対にやらないこと**：
   - 大賀VSLの「ダサめのフォント」や「煽り赤背景」をそのままコピーしない
   - 安っぽいクリップアートやストックイラストを使わない
   - 文字を1スライドに詰め込みすぎない（指定文字数を守る）
4. **目指す質感**：
   - Apple Keynote のテンプレートのような**洗練された見た目**
   - Notion / Linear / Stripe のような**ミニマルでモダンなトーン**
   - 「人が時間をかけてデザインした」感じ（AI生成感を出さない）

## 2. タイポグラフィ

### 使用フォント（必須）

**本文・見出しすべて**：以下のいずれかを使用（優先順）

1. **第一候補**：「Noto Sans JP」（Google Fonts・無料・モダン）
2. **第二候補**：「ヒラギノ角ゴ ProN W6 / W3」（macOS標準）
3. **第三候補**：「游ゴシック Medium / Regular」（Win/Mac両対応）

**絶対に使わない**：
- MS Pゴシック
- メイリオ（古い印象）
- HG創英角ポップ体 など装飾系
- スタイリッシュ系のセリフフォント（VSLには不適）

### サイズ階層

| 階層 | サイズ | 用途 |
|---|---|---|
| Display | 96-120pt | フルブリードの極大メッセージ（「お金＜時間」など1〜2語） |
| Title | 64-80pt | 主張・宣言・タイトル |
| Subtitle | 40-52pt | 中見出し・標準メッセージ |
| Body | 28-36pt | 本文・箇条書き項目 |
| Caption | 18-22pt | 補足・出典・人物業種 |
| Footer | 14-16pt | 字幕・最小文字 |

### ウェイト

- **タイトル系**：Bold（W6 / 700）
- **本文系**：Medium（W5 / 500）または Regular（W4 / 400）
- **強調キーワード**：Bold（W7 / 700）＋カラー変更

## 3. 共通レイアウト要素

### 顔出しワイプ枠（全スライド共通）

- **位置**：右上
- **サイズ**：480×270px（1920×1080の25%×25%）
- **形状**：角丸 16px
- **狙い**：話者の顔を常時表示。各スライド生成時に「右上の顔ワイプは別レイヤーで合成される」前提で、その領域に重要要素を置かない

### ナレーション字幕エリア（全スライド共通）

- **位置**：画面下部
- **高さ**：120px（下端から）
- **背景**：半透明黒（`rgba(0,0,0,0.7)`）または何もなし
- **テキスト**：白＋黒縁取り、サイズ 36-40pt
- **狙い**：別ツールで自動生成される字幕が乗る前提。下端120pxを空けておく

### セーフゾーン

- 上下左右に **120px のマージン** を確保
- 重要なテキストはこのセーフゾーン内に配置

### 上部セクション帯（白背景＋図解スライドのみ）

- **位置**：上部左寄せ
- **形式**：縦線 `|`（太さ6px・Primary Mid色）＋ セクション名（28pt・Text Dark）
- **例**：`| 雑務ゼロを実現する仕組みとは` / `| UTAGEが選ばれている理由`

## 4. 5つの基本デザインパターン（UTAGE版）

### パターン①：UTAGEブランドグラデーション（公式色そのまま）

**用途**：タイトル／主張・宣言／転換／CTA／個人ストーリー

**仕様**：
- 背景：左下 `#58A3E6`（Brand Blue）→ 右上 `#A75FF5`（Brand Purple）の斜め45度グラデーション
- 中央テキスト：白（`#FFFFFF`）＋影なし or 薄いシャドウ
- フォントサイズ：Title 64-80pt
- レイアウト：中央寄せ・1〜3行
- 装飾：最小限。背景にうっすらドットや幾何学パターン（透明度10%以下）可

**サンプル指示**：
> 「1920×1080、背景は左下#58A3E6から右上#A75FF5への斜め45度グラデーション、
> 中央に白文字 Noto Sans JP Bold 72pt で『◯◯◯◯◯』を3行配置、上下左右マージン120px、
> 右上480×270pxは空白（顔ワイプ用）、下120pxは空白（字幕用）」

---

### パターン②：ディープパープル（大賀の赤背景の代替）

**用途**：痛みの言語化／一網打尽宣言／反論先回り

**仕様**：
- 背景：`#6C3D9F` (Deep Purple) フルブリード ※赤を使わず深い紫で「痛み・重さ」を表現
- アクセント：右上または左上に `#C56B5A`（Soft Coral）の小さな三角や帯（強調マーク）
- テキスト：白特大（80-96pt）、中央寄せ、2〜4行
- 強調キーワードのみ Soft Coral または `#D3AFFA` (Soft Purple)

**サンプル指示**：
> 「1920×1080、背景#6C3D9Fフルブリード、左上に幅60pxの#C56B5A縦帯、
> 中央に白文字 Noto Sans JP Bold 88pt で『◯◯◯◯◯』を3行、強調キーワード『◯◯』だけ#C56B5A、
> 余白に粒子ノイズ（透明度5%）を入れて質感を出す」

---

### パターン③：ホワイトフィギュア（大賀の白＋図解の継承）

**用途**：自己紹介実績／市場データ／マトリクス／ファネル図／3つのコア／数値表／受講者BA／まとめ

**仕様**：
- 背景：`#FAFAF7`（Background White）
- 上部セクション帯（縦線 `#58A3E6` または `#A75FF5` 6px ＋セクション名）
- 図解／表／チャート：細い線（1.5px）＋ `#4A8AC3` (Mid Blue) または `#8D50D0` (Mid Purple) で描画
- 強調キーワード：`#2563EB` (Highlight Blue) または `#D4A04C` (Highlight Gold)
- フォントサイズ：Subtitle 40pt / Body 28pt
- 装飾：上下にうっすら `#F1E7FD` (Tint Purple) または `#E5F1FB` (Tint Blue) のアクセント帯可

**サンプル指示（マトリクス）**：
> 「1920×1080、背景#FAFAF7、上部に|セクション名（縦線#A75FF5 6px、文字#1A1F36 Noto Sans JP Bold 28pt）、
> 中央に2×2マトリクス（線の太さ2px、色#5A6378）、4象限にそれぞれラベルとアイテムを配置、
> 強調セルのみ薄い#ABD1F2で塗り、上下に120pxセーフゾーン」

---

### パターン④：センチメンタル（大賀の写真背景の代替）

**用途**：理想未来の提示／感情モーメント／景色（3つ目の道）

**仕様**：
- 背景：抽象的なグラデーション or 風景写真（ストックフォトは使わずジェネレート）
- 上から半透明オーバーレイ `rgba(57,105,149,0.55)` (Deep Blue 透過) を被せて可読性確保
- テキスト：白特大（72pt）、中央寄せ
- 写真を使う場合：海・山・空・道などの**抽象的な風景**のみ。人物写真NG
- 風景のトーンは**青〜紫の冷色系**で揃える（UTAGEブランドと調和）

**サンプル指示**：
> 「1920×1080、背景は抽象的な海の地平線（紫がかった青系のグラデーション風景・UTAGEブランド色#58A3E6→#A75FF5に寄せたトーン）、
> 中央に白文字 Noto Sans JP Bold 72pt で『◯◯◯◯◯』、半透明オーバーレイ rgba(57,105,149,0.55) で可読性確保、
> 画像生成時はノスタルジック／センチメンタルなトーン」

---

### パターン⑤：ディープイマージョン（大賀の暗色背景の継承）

**用途**：反論先回り（会話風）／視聴者の心のつぶやき代弁

**仕様**：
- 背景：`#1A1F36`（最深チャコール）または `#396995`（Deep Blue）フルブリード
- テキスト：白 70-80pt、左寄せまたは中央寄せ
- 「」括弧の中に視聴者のつぶやきを書く
- 質感：背景に微細なノイズ（5%）または星雲のような暗いテクスチャ
- UTAGEブランド色との調和を保つため、純黒は避け、紺寄りor青紫寄りのダークを使用

**サンプル指示**：
> 「1920×1080、背景#1A1F36フルブリード、微細な星雲テクスチャ（透明度10%・紫青のもや）、
> 中央に白文字 Noto Sans JP Bold 76pt で『「◯◯◯◯◯◯」』を会話風に4行配置、
> 「」は1段大きく、本文は1段小さく」

## 7. デザイン品質チェックリスト

各スライド生成後、以下を確認：

- [ ] 1920×1080 PNG で出力されているか
- [ ] 顔ワイプエリア（右上480×270）が空いているか
- [ ] 字幕エリア（下120px）が空いているか
- [ ] フォントが Noto Sans JP / ヒラギノ / 游ゴ のいずれかか
- [ ] 文字数が指定範囲内か
- [ ] 色がUTAGEパレット内か
- [ ] 大賀の煽り赤を使っていないか
- [ ] クリップアート的なダサい装飾が混入していないか
- [ ] スマホ視聴でも読めるサイズか（最小28pt以上）

## 10. 困った時の判断基準

1. **「これってどのパターン？」と迷ったら**：シーンの感情トーンで判断
   - 主張／前向き → ①
   - 痛み／警告 → ②
   - 説明／データ → ③
   - 共感／没入 → ④
   - 内省／会話 → ⑤

2. **「文字を入れたい量より多い」と感じたら**：分割を検討（次のスライドへ）
3. **「色が浮く」と感じたら**：UTAGEパレット内で代替を探す
4. **「ダサい」と感じたら**：装飾を引く（足すのではなく引く）

---

**最終確認**：このドキュメントを参照しながら、Codexに対して各スライドを順次生成依頼してください。
不明点があれば、各シーンの仕様を別資料『大賀VSL_スライド構造分析_v1.xlsx』⑤シーン全体図と照合して判断してください。

## 11. テンプレ関数化アプローチ（**重要・必読**）

### なぜテンプレ関数化が必須か

220枚を「220個の独立した生成タスク」として扱うと、**同じパターンのスライドが微妙にバラつく**事故が起きます：
- 同じ「実績カード」なのに、ある時は左寄せ・ある時は中央寄せ
- 強調色のアンバーが、ある時は `#D4A04C`・ある時は近似色になる
- 装飾の濃淡が一定しない

→ **対策：全220枚を5つのテンプレ関数（＋カード型のサブ関数）にデータを流し込むだけで生成する。**

### 推奨ワークフロー

| Step | 内容 |
|---|---|
| **1** | この章で定義する5パターン分のレンダリング関数（PIL/Pillow使用）を実装 |
| **2** | 各関数で代表サンプルを1枚ずつ出力（計5枚） |
| **3** | 人間がOK → 関数微調整があれば反映 |
| **4** | 220枚分のデータをすべての関数に流して一括生成 |
| **5** | 出力後、サムネ一覧でQA |

**重要原則**：「絶対に1枚ずつ自由生成しない」「同じパターンのスライドは必ず同じ関数を経由する」

### 関数実装時の絶対ルール

1. **同じ関数を呼べば必ず同じスタイル**（外部から色やフォントを上書きしない）
2. **テキスト量は引数の `text_lines` の中身だけが変わる**（フォントサイズ・位置・装飾は固定）
3. **顔写真は円形クロップで320×320に固定**（カード型）
4. **マージン・セーフゾーン・ワイプエリアは全関数で共通定数を参照**

### 関数追加が必要な場合

新たなレイアウトが必要（例：UTAGE機能一覧スライド用の「3アイコン横並び」）になった場合は、**既存の5関数を改造せず、新関数 `render_pattern_3_3icons()` のように追加する**こと。既存関数の挙動を変えると過去スライドの再生成時に結果がブレるため。

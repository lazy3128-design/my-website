# UTAGE VSL 制作根拠資料 ―「何を参考にしたのか」への回答

**作成日**：2026-05-18
**目的**：UTAGE VSL（全171スライド）の構成・台本が、思いつきではなく **実出稿データに基づくVSLリサーチ** と **直近の参考モデル** を分析した上で設計されたことを示す。

---

## 0. 結論（先に要点）

今回のUTAGE VSLは、以下の**3層の根拠**の上に作られている。

| 層 | 何を | 役割 | ファイル |
|---|---|---|---|
| ① リサーチ | 国内外17本のVSLを実出稿期間で格付けし横断分析 | 設計の「軸」（どんな構成が"実際に売れている"か） | `UTAGE_リサーチVSL分析_v1.xlsx` |
| ② 参考モデル | 大賀聖也「ハイチケットウェビナーファネル構築講座」 | 構成の「型」（直近で最も近い成功VSLの流れ） | `参考モデル_大賀聖也_…_文字起こし.md` |
| ③ 制作基準 | Teruさん添削の蓄積（A〜T章のガイドライン） | 表現・トーン・繋ぎの「判断基準」 | `マーケ作業ガイドライン.md` |

171スライドの構成は、**①で「売れる型」を特定 → ②で直近の具体モデルに当てはめ → ③の基準で日本語・UTAGE向けに表現を最適化**、という順で設計された。本資料はその対応関係を一つずつ示す。

---

## 1. リサーチの方法論 ―「なぜこの17本なのか」

VSLの良し悪しは主観で決めず、**「実出稿期間」という唯一の客観指標**で評価した。

> 出稿期間は「そのVSLが利益を出し続けているか」の唯一の客観指標。長期間出稿が継続しているVSLほど、構成・オファー・ファネル全体が機能している確率が高い。
> （`UTAGE_リサーチVSL分析_v1.xlsx` VSL横断分析シート ❶ より）

この基準で17本をTier S〜Cに格付けし、**Tier S/A（出稿3ヶ月超＝実際に売れていると推定できる7本）**から共通項を抽出した。つまり「良さそうに見えるVSL」ではなく「**広告費を払い続けられている＝市場が証明したVSL**」だけを設計の根拠にしている。

**最重要参考に選定した上位5本（リサーチ内の優先順位）**

1. Allie Bloyd（SaaS直販・$47+返金保証・**1年7ヶ月**出稿）― UTAGEの14日トライアルと最も近い構造
2. 早川（日本語VSL最長・**6ヶ月**・30分教育型）― 日本語での成功型
3. 筒井啓樹（UTAGE上に構築・80分教育型・**3.5ヶ月**）― 同一プラットフォーム事例
4. Paul Xavier（PASTOR教科書・$698直販・**6.5ヶ月**）― 誤解破壊と事例分散
5. Adam Cerra（**2年3ヶ月**・短尺権威型）― 最長出稿の権威性設計

## 2. リサーチの結論 → 171スライドへの反映（横断分析の各項目を追跡）

リサーチが導いた結論（xlsx横断分析 ❷〜❾）が、171スライドのどこに反映されているかを対応づける。

### 2-1. 共通項（❷）→ 構成判断

| リサーチが出した結論 | 171スライドでの反映 | 該当スライド |
|---|---|---|
| 共通項①：自己紹介で始めない。数字か他者成果で掴む | 内なる声＋問題提起で開始。自己紹介はゼロ。開発者紹介は本編③まで遅延 | 1〜6 / 75〜88 |
| 共通項②：尺は短いか長いかの二極化（中間20-25分は0件） | 約64分のフル教育型に振り切り（中途半端な尺を回避） | 全体 |
| 共通項③：CTAは低リスクの次の一歩 | 「14日間無料トライアル」へ誘導。購入要求なし | 151〜171 |
| 共通項④：「自分が実践している」証拠 | 開発者いずみ氏の実績・1.5万社/100万人の導入実績 | 77 / 82〜88 |
| 共通項⑤：事例は量か深さに振り切る | 事例を5名分まとめて配置（中途半端な3件を回避） | 114〜131 |

### 2-2. 設計指針（❻）→ 全体構成

リサーチの推奨構成は「**教育型VSL → 一定時間経過後に14日無料トライアルのリンクを表示**」。171スライドはこれを直接踏襲：

```
リサーチ❻の推奨パート構成        →  171スライドの対応
冒頭：成果/問題提起               →  フック 1〜27
問題提起：ツール乱立の逆説         →  本編① 28〜52
権威性：開発実績/導入社数          →  本編③ 75〜88
教育：一元化の構造的メリット       →  本編② 53〜74 / ④ 89〜113
事例：異業種Before→After          →  本編⑤ 114〜131
CTA：時間経過後に14日無料表示      →  クロージング 149〜171
```

### 2-3. フック類型（❽）→ 冒頭設計

リサーチはフックを5類型に分類し、UTAGEには「Type A（成果連打）＋Type B（断言否定）のハイブリッド」を推奨。171スライドのフックは、ガイドライン（toB寄りtoC・商材臭回避）に合わせ、**Type Bの"断言否定"を「内なる声→常識破壊」の形にやわらげて実装**（スライド1〜3「その思考こそが成長を止めている」）。リサーチの推奨を、制作基準③でトーン調整した実例。

### 2-4. 時間配分（❼）→ パート尺

リサーチの結論「中尺〜長尺は教育パートが50-63%」に対し、171スライドは本編①〜⑥（教育＋事例）が全171枚中の大半を占め、フックとクロージングを抑えた構成になっている（教育偏重＝早川モデル準拠）。

## 3. 直近モデル（大賀VSL）との構造対応 ―「型」の出所

リサーチで特定した「売れる型」を、**直近で最も近い具体的成功モデル＝大賀聖也VSL**（リサーチ内VSL16／筒井氏のメンター）に当てはめて構成を起こした。両者の流れはパート単位でほぼ一致する。

| 大賀VSLの構成要素 | 大賀VSLの内容（文字起こしより） | 171スライドの対応 | 該当スライド |
|---|---|---|---|
| 掴み（数字＋理想の問いかけ） | 24日2,112万・ROAS4951%／「〜になったらいかがでしょうか」 | 内なる声＋効率化の限界 | 1〜6 |
| 常識破壊 | 「古い理論＝ジャーニー型→今はパルス型」 | 「効率化＝速度、量は減らない／ツール乱立が複雑さを増やす」 | 4〜6 / 28〜52 |
| あなたのせいではない | 代理店乱立・情報過多・実践機会の欠如（外的要因） | 環境変化・SaaS過剰を外的要因として客観提示 | 7〜9 / 49〜50 |
| 権威性・ストーリー | ラスベガス遠征／累計23億／開発者本人 | いずみゆう開発者ストーリー・実績 | 75〜88 |
| 独自概念の確立 | 「ハイチケットウェビナーファネル」 | 「事業の基盤を整える＝UTAGE」＋One Thing「雑務ゼロ」 | 52 / 75 / 88 |
| 反論先回り | 「高額ばかり売って大丈夫？」等を都度処理 | 「オールインワンは中途半端では？」等を都度処理 | 78〜79 / 92 / 153 |
| コア教育（3つの柱） | ①ハイチケット開発②戦略的ファネル③クロージング | ②一元化／④売れる流れ／⑤事例 の3教育ブロック | 53〜131 |
| 事例（量で証明） | とが/宮部/鈴木…を各コアで連打 | 事例5名をまとめて提示 | 114〜131 |
| **クロージング「3つの道」** | ①何もしない②独学③一緒に進む | **①ブラウザを閉じる②独学③UTAGEを試す** | **164〜166** |
| 決断遅延の警告 | 「現状維持は破滅への近道」「決断を先送りにするな」 | 「問題は明日ひとつ増える」「動かない＝静かに悪化」 | 167〜168 |
| 低リスクCTA＋限定 | 無料セッション・枠が埋まり次第終了 | 14日無料トライアル・3日以内特典 | 151〜163 / 169〜170 |

**特に決定的なのはクロージングの「3つの道」**。大賀VSLの「①何もしない②独学で進む③一緒に進む」という3択提示と決断遅延の警告が、171スライド164〜168にほぼ同型で実装されている。これは構成を大賀モデルから取ったことの最も明確な痕跡である。

## 4. なぜ「そのまま流用」ではなく「再設計」なのか（制作基準③の役割）

大賀VSLとリサーチ上位は、そのままでは使えない。理由はターゲットと商材が違うから。ガイドライン S-17（参考素材を借用する時、文脈ごと確認する）に従い、以下を変換した。

| 項目 | 参考元 | UTAGE版での変換 | 変換の根拠 |
|---|---|---|---|
| 商材 | 高額コンサル/コーチング | SaaS（UTAGE）の14日無料トライアル | リサーチ❻：Allieモデル（SaaS直販）が最適 |
| CTA強度 | 個別セッション・煽り強め | 「14日間無料で試す」低リスク・煽り抑制 | ガイドラインA：toB寄りtoC、商材臭回避 |
| トーン | 1人語り・感情強め | 完全ナレーション型・冷静かつ情熱的 | ガイドラインA-3 / S-21 |
| フック | Type B断言否定（強い） | 「内なる声→常識破壊」にやわらげ | ガイドラインB-4：直接的すぎる表現を柔らかく |
| 概念名 | ハイチケットウェビナーファネル | 「事業の基盤を整える」「雑務ゼロ」 | リサーチ狙い④：独自概念名が必須 |

つまり「**売れている型（①②）を骨格に採用し、UTAGEのターゲットと商材に合わせて表現を再設計（③）した**」が制作プロセスの実態であり、丸写しではない。これも参考にした根拠そのものである。

## 5. まとめ ―「何を参考にしたのか」への一文回答

> **国内外17本のVSLを実出稿期間で格付けして横断分析し（リサーチ資料）、その結論で特定した"売れる教育型VSLの型"を、直近で最も近い成功モデルである大賀聖也のハイチケットウェビナーファネルVSLに当てはめて構成を起こし、Teruさんの制作基準でUTAGEのターゲット・商材・トーンに合わせて再設計した。**

- 構成の骨格（フック→常識破壊→権威性→概念→教育→事例→3つの道クロージング）＝**大賀モデル＋リサーチ上位の共通型**
- 14日無料トライアルへの低リスク誘導・教育偏重の尺＝**リサーチ❻❼の結論**
- 表現・トーン・繋ぎ＝**ガイドライン（Teruさん添削の蓄積）**

裏付け資料はすべて同フォルダ内に保管：

|---|---|

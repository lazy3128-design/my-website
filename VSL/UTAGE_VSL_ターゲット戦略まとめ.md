## 1. 結論:今回のVSLが狙うべき層

**「あ、いいかも客」**

一言で言うと:

> 絶望度は中くらい。その分野の情報感度は低い。経済的な属性は良い。比較検討せず、偶然の接触で「あ、いいかも」と軽く動く層。

## 2. 4象限ターゲットマトリクス

広告ターゲットは、「情報感度」と「属性(経済力・本気度)」の2軸で4つに分かれます。
（図は画像ファイル参照）

```
         　　            情報感度 高い
     　　                     ▲
 　　                         │
      　 　ジプシー層         │    中上級者
      　 　(悩み深い×高感度) │    (強者の領地)
          　　                │
 属性 悪い ◀─────────┼─────────▶ 属性 良い
     　　                     │
      　　 常弱ターゲット     │    あ、いいかも客
      　 　(悩み深い×低感度) │    (絶望度中×低感度)
           　　               │
               　　           ▼
                  　　   情報感度 低い
```

### 各象限の特徴

#### 左上:ジプシー層(悩み深い × 情報感度高い)
- 過去に買い物で失敗している
- 徹底的に比較検討する
- SNSで「◯◯ 比較」を検索する層
- 何度も失敗しているので慎重
- **広告では取れない**(比較検討フェーズに入ってしまう)

#### 右上:中上級者(情報感度高い × 属性良い)
- 情報感度も経済力も高い
- SNSやブランドで取る層
- 強い実績・ブランドがないと新規参入は困難
- **既に取り込み済み**の可能性が高い領域

#### 左下:常弱ターゲット(情報感度低い × 属性悪い)
- お金がなく、知識もない
- 多くの広告がここにアプローチして消耗している
- 取っても売上につながらない
- **踏み込まない領域**

#### 右下:あ、いいかも客(情報感度低い × 属性良い) ← ここを狙う
- その分野に関しては詳しくない
- でも経済的な属性は良い
- 悩みは深くないので比較検討しない
- 「それが手に入るなら嬉しい」レベルの軽い動機で動く
- **Meta広告で偶然接触させる層**

＜参考モデル＞
コンテンツビジネス1人経営者(大)
  ↓
売上が立っている層(中)
  ↓ ← ここで分岐
  ├─ 専門家に丸投げ派 → ローンチ屋・構築代行に流れる(広告対象外)
  └─ 自分で運用派 → 「あ、いいかも客」候補

  さらに「自分で運用派」の中で
  ├─ 既に情報強者 → 海外ツール・比較検討派(Google広告対象)
  └─ マーケツールに疎い → 「あ、いいかも客」 ← 広告で取れる層

## 3. 重要な逆説:「悩みが深い=今すぐ買う」は間違い

マーケティングの常識では「悩みが深い人ほど今すぐ買ってくれる」と思われがちですが、これは**逆**です。

### 悩みが深い人の実際の行動

1. 長年解決できない課題を抱えている
2. 過去に何度か買い物で失敗している(ジムに通ったが痩せなかった、等)
3. だから次は慎重になる
4. よく調べるようになる
5. SNSで比較検討する

つまり**悩みが深い人ほど、広告を見ても「また広告か」と距離を取る**。クリックしない。クリックしても購入しない。

### 広告で取るべき層の逆転

広告で取るべきは、**悩みがそこそこで、経済力があり、情報感度が低い層**です。彼らは:

- 切迫していない
- だから慎重にならない
- 偶然出会った情報を素直に受け取る
- 「いいかも」と思ったら試す
- 比較検討しない

## 3.5 時間軸の視点:問題の「慢性化」を見る

ここまでの議論は「悩みの深さ」「情報感度」「属性」という**静的な属性**でターゲットを分類してきました。ここに**時間軸**を加えると、もう一段解像度が上がります。

### 同じ人でも、時間とともに象限が変わる

例えば「毎日のツール切り替えに疲れている1人経営者」がいるとします。この同じ人物は、時間の経過とともに象限を移動していきます。

#### 初期段階(違和感を感じ始めた頃)
- 悩み: 中程度
- 情報感度: 低い(まだ解決策を探していない)
- 行動: 「こういうの嫌だな」と思うが、まだ何もしていない
- → **あ、いいかも客** ✓

#### 中期段階(解決策を探し始めた頃)
- 悩み: 中〜高
- 情報感度: 上昇中(調べ始めている)
- 行動: オールインワンツールをいくつかググってみる
- → **ジプシー予備軍**

#### 慢性化段階(何度か試して失敗した後)
- 悩み: 深い(諦めモードが混じっている)
- 情報感度: 高い(失敗経験から学んでいる)
- 行動: 新しいツールの広告を見ても「どうせ同じだろう」と距離を取る
- → **完全なジプシー層** ✗

### 重要な示唆

**同じ悩みを持つ同じ人でも、時間が経つと象限が右上に移動していき、広告で取れなくなります。**

つまり広告ターゲットには**"旬"がある**ということです。旬を過ぎた(=慢性化した)人は、どれだけ悩みが深くても広告では取れません。

### 具体例

| 状態 | 悩みの深さ | 広告効果 |
|---|---|---|
| UTAGEの存在を知らず、ツール切り替えに最近ストレスを感じ始めた40代 | 浅い | **旬(取れる)** |
| 過去に3つのMAツールを試して挫折し、諦めて手作業に戻った40代 | 深い | 旬を過ぎた(取れない) |

**後者の方が悩みは深いのに、広告では取れない。前者の方が悩みは浅いのに、広告ではよく動く。**

これが「悩みが深い人は広告では取れない」という逆説の正体です。悩みが深い=慢性化している=何度も解決を試みている=失敗経験がある=慎重になっている、という連鎖構造。

### VSL冒頭フックへの影響

この視点を踏まえると、VSL冒頭で**避けるべき表現**と**使うべき表現**がはっきりします。

#### NG: 慢性化している人向けの言葉(避ける)
- 「何度もツールを変えてきたあなたへ」
- 「色々試したけど、どれも続かなかったあなたへ」
- 「MAツールで挫折した経験はありませんか?」

これらは**「既に何度か失敗している=慢性化している=ジプシー層」に呼びかける言葉**なので、今回のターゲットには合わない。むしろジプシー層を呼び寄せてしまい、CVを下げる原因になる。

#### OK: 慢性化していない人向けの言葉(使う)
- 「事業は回っているけど、毎日の管理業務に違和感を感じ始めていませんか?」
- 「このままの働き方を続けていて大丈夫かな、と思うことはありませんか?」
- 「朝起きた瞬間から通知の処理が始まっていませんか?」

これらは**「違和感を感じ始めたばかりの人」に呼びかける言葉**。今回のターゲットである「あ、いいかも客」に届く。

### ターゲット像の補正

この時間軸の視点を加えると、「あ、いいかも客」の定義がより鮮明になります:

> 「あ、いいかも客」とは、情報感度が低く、属性が良いだけでなく、**問題がまだ慢性化していない初期段階にいる人**である。違和感を感じ始めたばかりで、まだ能動的に解決策を探していない、諦めモードに入っていない層。

## 3.6 緊急性と悩みの深さは別物

ここまで何度か「悩みが深い」「緊急性がある」という言葉を使ってきましたが、この2つは**全く別の概念**として分けて考える必要があります。混同すると戦略がぶれます。

### 2つの定義

- **緊急性** = 「その状態から今すぐ抜け出したい」という欲求の強さ
  - 時間軸: **今**
  - 性質: 衝動、欲求、今日動く理由
  - 例: 家の鍵が壊れた → 今すぐどうにかしたい

- **悩みの深さ** = 悩んでいる期間の長さ(過去の蓄積)
  - 時間軸: **過去の累積**
  - 性質: 慢性、染み付き、日常化
  - 例: 3年間薄毛で悩んでいる

この2つは独立した軸です。普通のマーケティング理論では「悩みが深い=緊急性が高い=今すぐ買う」と考えがちですが、実際は逆のことが多い。**長く悩んでいる人ほど、諦めや麻痺が混じって今日動く理由がなくなっている**からです。

### 4象限で整理

```
                     緊急性 高い
                         ▲
                         │
   長年薄毛で悩むが       │    今朝鍵が壊れた
   今日はどうでもいい     │    →今すぐ何とかしたい
   (悩み深い×緊急低)     │    (悩み浅い×緊急高)
                         │
   悩み深い ◀─────────────┼─────────────▶ 悩み浅い
                         │
   長年の不満が           │    今朝ちょっと
   日常に馴染んでいる     │    違和感を感じ始めた
   (悩み深い×緊急低)     │    (悩み浅い×緊急低)
                         │
                         ▼
                     緊急性 低い
```

### なぜ「悩みが深い人は広告では取れない」のか(真の理由)

以前から「悩みが深い人は比較検討に入る」と説明してきましたが、もっと根本的な理由はこちらです。

**悩みが深い = 長く悩んでいる = 緊急性が下がっていく = 今日動く理由がない**

慢性化して日常に馴染んでいるから、広告を見ても「まあ今日じゃなくていいか」と流される。比較検討以前に、そもそも**今日行動を起こすモチベーションが存在しない**。

### 「あ、いいかも客」の強みの再定義

「あ、いいかも客」は悩みが浅い。この一見弱みに見える特徴が、実は広告で動かすための**最大の強み**です。

- 悩みが深い人 → 緊急性が下がっていく(諦めモード、麻痺)
- 悩みが浅い人 → 違和感がまだ新鮮(諦めていない)
- だから偶然の接触で火がつく可能性がある
- しかも「長年悩んでいない」から比較検討しない
- 決断コストが低い

## 3.7 Google広告とMeta広告の棲み分け

2軸マトリクスを理解すると、**広告チャネルの使い分け**が論理的に説明できます。

### Google広告 = 右上(悩み浅い×緊急高い)
- ユーザーは能動的に検索している
- 「今すぐ解決したい」という明確な意図がある
- 例: 「MAツール 乗り換え」「オールインワン マーケティング」で検索している人
- キーワード+スペック訴求型LP+短尺VSLで取る

### Meta広告 = 右下(悩み浅い×緊急低い)
- ユーザーはフィードを受動的に見ている
- 「今すぐ」という意図はない
- 例: Instagramを夜にスクロールしていて、たまたま流れてきた広告を見る人
- 気づき+軽い解決策の提示で取る

### 両方とも「悩みは浅い」が、緊急性で分岐

普通のマーケティング理論では「Google=顕在層、Meta=潜在層」と説明されますが、より正確には「Google=悩み浅い×緊急高、Meta=悩み浅い×緊急低」の棲み分けです。

**どちらも"悩みが深い層"は対象にしていません**。悩みが深い層はどの広告でも取れない。

### UTAGEでいうと

- **Google広告で取る層**: 海外ツールや大規模ツール運用で、今月のコストが限界。今すぐ乗り換えたい → スペック訴求で取る
- **Meta広告で取る層**: 事業は回っているが毎日の運用に違和感。解決策は探していない → 気づき訴求で取る(今回のVSLの対象)

## 3.8 Meta広告で「緊急性」を作る方法

「あ、いいかも客」は緊急性がない状態で流入してきます。VSLの役割は、**その場で瞬間的に緊急性を作ること**です。

### やってはいけないこと

**時間制限系の外発的な煽り**
- 「24時間限定!」「残り3名!」のような時間制限
- 「今すぐ!」「急いで!」のような直接的な煽り
- これは本来の緊急性(内発的な欲求)ではなく、外部からの強制
- 「あ、いいかも客」は煽られると警戒する(広告臭さを感じる)

**緊急性がある前提の話法**
- 「今すぐ何とかしたいあなたへ」
- これはGoogle広告のコピー。Meta広告には合わない
- ターゲットは「今すぐ何とかしたい」と思っていない

### やるべきこと

**「今動かない未来」を具体的に描写する**

時間の経過を想像させる形で、内発的な緊急性を作り出す。

例:
- 「このままの1日を、あと何百回繰り返すつもりですか」
- 「1ヶ月後のあなたも、同じように朝のメールチェックから始まります」
- 「半年後も、同じ手作業を同じ順番で繰り返しています」

「煽り」ではなく、**時間の経過という事実を突きつけることで、薄い違和感を行動欲求に変える**。これが「あ、いいかも客」に対する緊急性の作り方です。

## 3.9 4象限それぞれの取り方(UTAGE全体戦略)

ここまでは今回のMeta広告VSL案件(右下)にフォーカスしてきましたが、**4象限すべてに取り方が存在します**。今回は取らない象限についても、将来のUTAGE全体戦略の地図として整理しておきます。

### 左上: 悩み深い × 緊急低い(諦めモード型)

何度も失敗してきて、解決を諦めている層。長年の蓄積で「もう無理だ」と内面化している。

**取るための設計**
- チャネル: YouTube または Instagram Reels の**連載型コンテンツ**
- 期間: 最低3〜6ヶ月
- 構造: 共感 → 再定義 → 希望 → 行動、の4段階
  - 共感フェーズ: 「あなたは悪くない」と認める
  - 再定義フェーズ: 「失敗の理由はあなたではなく構造にあった」と再定義
  - 希望フェーズ: 「ここにたどり着いた人にだけ見える世界がある」
  - 行動フェーズ: ようやくUTAGEを提案

**LTV**: 高い(諦めから救ってくれた存在には深い感謝が生まれ、継続率が高い)
**獲得難度**: 極めて高い(時間もコストもかかる)
**今回やるか**: ✗(広告単発案件ではなく、泉さん個人ブランディングや公式YouTubeで長期的にやる施策)

### 右上: 悩み浅い × 緊急高い(鍵壊れた型)

今すぐ解決したい明確な痛みがある層。能動的に検索する。

**UTAGEでの具体状況例**
- 明日ローンチなのに決済ツールが動かない
- 使っているツールの仕様変更でファネルが壊れた
- 構築代行を頼んでいた人が急にいなくなった
- 今の月額コストが限界に達した
- 大型プロモーションを組むのに今のツールでは無理

**取るための設計**
- チャネル: Google検索広告(メイン)+ YouTube広告(サブ)
- キーワード: 「MAツール 乗り換え」「ClickFunnels 代替」「Lステップ 高い」等
- LP: 比較表重視、スペック勝負
- 訴求: 「日本製」「日本語サポート」「即日対応」

**LTV**: 中程度(機能で選んだ層なので、より良い機能のツールが出たら移る可能性)
**獲得難度**: 低(能動的に探しているのでCVRが高い)
**今回やるか**: 別案件として検討する価値あり

**注意点**: ChatGPTやClaudeなどのAIに「UTAGEとClickFunnelsの比較」を聞く人が増えている。単なる比較広告では勝てず、**日本製・日本語サポート・即日対応**という日本市場特有の強みを前面に出す必要がある。

### 右下: 悩み浅い × 緊急低い(あ、いいかも客) ← 今回のVSLの対象

違和感を感じ始めたばかりで、解決策を探していない層。フィードの偶然接触で動く。

**今回のVSLはこの層を狙う**。詳細はセクション5以降。

### 左下: 悩み深い × 緊急低い(日常馴染み型=麻痺層)

**当初「取れない層」と定義していたが、訂正します**。この層は諦めているのではなく、**麻痺している**。痛みを感じなくなっているだけで、気づけば動く可能性があります。

**麻痺層と諦めモード層の違い**
- 諦めモード(左上): 何度も失敗して、もう解決を信じていない
- 麻痺層(左下): 長年の不満が日常に馴染みすぎて、痛みとして認識していない

**取るための設計: 「当たり前の破壊」**

この層を動かすには、「それは当たり前じゃない」という衝撃を与える必要があります。

1. **他人の日常を見せる**: 「週3日しか働いていない経営者」「朝メールチェックがない経営者」の具体的な生活を見せる。自分の当たり前が他人の当たり前と違うことに気づかせる
2. **時間の可視化**: 「あなたが今日、ツール管理に使った時間は◯分です」と数値化して、麻痺している感覚を数字で突きつける
3. **過去との強制比較**: 「1年前の自分と今の自分、事業は何が変わりましたか?」と時間軸で比較させる。麻痺した人は現在しか見ていないので、過去と比較すると変化のなさに気づく

**広告コピー例**:
- 「朝、メールチェックから1日を始めていませんか?」
- 「実はそれ、あなたが選んだわけではなく、ツールの都合で始まっています」
- 「世界には、朝の最初の30分を家族と過ごしている経営者がいます」

**LTV**: 最高級(日常を変える体験をした人は絶対に戻れない、口コミ効果も強い)
**獲得難度**: 高い(麻痺している人の気づきを起こすのは、諦めている人より難しい場合もある)
**今回やるか**: 将来検討(UTAGEの隠れた金脈になる可能性)

## 4. 絶望度 × 情報感度マトリクス

もう一段細かく見ると、「絶望度」と「情報感度」のマトリクスで考えることができます。

| | 情報感度 低い | 情報感度 高い |
|---|---|---|
| **絶望度 高い** | 常弱層(売れない) | ジプシー層(比較検討) |
| **絶望度 中** | **← ここが広告で狙うべき層** | 中上級者(既に取り込み済み) |
| **絶望度 低い/ゼロ** | 何やっても売れない | 売れない |

### Meta広告で狙うべき最適ゾーン

**「絶望度 中 × 情報感度 低い」**

- 絶望度ゼロは動かない(痛みがないから)
- 絶望度高いはジプシー化する(比較検討に入る)
- **中くらいの絶望度が、広告で最も動きやすい**

## 5. UTAGE文脈での「あ、いいかも客」の人物像

### 基本属性
- 業態: コンテンツビジネス系の個人事業主(講座・コンサル・コーチ・カウンセラー・講師業)
- 年代: 30〜50代中心
- 月商: 数十万〜数百万円程度
- 事業段階: それなりに伸びている(売上は立っている)
- 運営: 1人 or 少人数
- UTAGE認知: **名前を知らない**(ここが最重要条件)

### 情報感度
- SNSやYouTubeで能動的にツール比較をしていない
- 「オールインワンツール」を検索したことがない
- マーケティング情報源は限定的(本、知り合いの紹介、セミナー参加)
- 新しいツール導入に対しては慎重 or 疎い
- ただし情弱ではない(基本的なツール=メール配信、LINE公式、Zoom、Google系は使える)
- **過去に複数のMAツールを試して挫折した経験がない**(=問題がまだ慢性化していない)

### 心理状態(ここが核心)
- 事業はちゃんと回っている
- でも自分が動き続けないと止まる
- 毎日のオペレーションで1日が終わる
- 「このままじゃいつか倒れる」という漠然とした不安がある
- **でも具体的に何を変えればいいか分からない**
- 解決策を探す時間もない
- **「もう少し頑張ればいつか楽になる」と思い込んで先送りしている**

### 行動パターン
- 朝はメールチェックから始まる
- 1日に何度もツールを切り替えて対応している
- 夜も仕事のことが頭から離れない
- 週末も「溜まった作業を片付ける日」になっている
- 家族や自分の時間がほぼない

### 1行要約

> 「UTAGEの存在を知らないまま、自分の手と時間で事業を回し続けていて、"このままじゃダメだ"と薄々感じているが、解決策を探す余裕もなく先送りしている、40〜50代のコンテンツビジネス1人経営者」

### 「あ、いいかも客」の本質:ジャンル特化型の情報非対称性

重要な認識として、**「あ、いいかも客」は固定された層ではありません**。同じ人でも、ジャンルによって象限を移動します。

例:
- あるマーケターは、マーケティング分野では右上の情報強者
- でも健康食品のジャンルでは右下の「あ、いいかも客」になる
- 投資のジャンルでは左上の諦めモードかもしれない
- 恋愛のジャンルでは左下の麻痺層かもしれない

つまり「あ、いいかも客」の正体は、**そのジャンルに詳しくない人**です。他のジャンルでは情報強者でも、特定のジャンルでは素人になる。これは人間誰しもが持つ「ジャンル特化型の情報非対称性」です。

### UTAGEの「あ、いいかも客」の再定義

これを踏まえると、UTAGEの「あ、いいかも客」はこう定義できます:

> **コンテンツビジネスは本業として回しているが、マーケティングツール分野には詳しくない1人経営者**

本業では情報強者かもしれない。例えば:
- ヨガ10年のキャリアを持つ講師
- 資格も経験もあるコーチ
- 業界で名の知られたカウンセラー

でも**マーケティングツール分野では素人**。「ファネル」「ステップ配信」「MA」という言葉すら知らない or ぼんやりしか理解していない。これが「あ、いいかも客」の実像です。

### この視点がもたらす戦略上の含意

1. **本業では情報強者であることを尊重する**: 「あなたは素人」扱いしてはいけない。本業のプロとして敬意を払った上で、「マーケティングツールという別分野では知らないことがあって当然」という文脈で話しかける
2. **専門用語の扱い**: マーケティングツール分野の専門用語(ファネル、CVR、ROAS等)は避ける。でも本業の専門用語は尊重する
3. **トーン**: 「教えてあげる」ではなく「隣の分野からのお知らせ」のトーン。上から目線はNG

## 6. なぜこの層のLTVが高くなるか

「あ、いいかも客」がUTAGEを導入した場合、LTVが構造的に高くなる理由:

1. **導入後は本気で使う**: 軽い動機で試したが、効果を感じると手放せなくなる(「とりあえず導入→解約」パターンに陥らない)
2. **月額を払い続ける経済力がある**: 事業が既に回っているため
3. **乗り換え候補を調べない**: 他に比較検討する情報源を持っていないので、継続しやすい
4. **時間が戻る体験=戻れない状態**: 一度自動化の快適さを知ると、以前の手作業に戻れない
5. **意思決定が早い**: 1人経営者なので社内調整の離脱がない

### 補足:この人物像の導出プロセス

xlsxのアンケートデータは「既に利用している人のデータ」なので、「未利用者の特徴」は直接は見えません。そこで逆算しました。

既存ユーザーの中で、**「もっと早く使っておけばよかった」「気づくのが遅かった」系のコメントをしている人**を拾うと、彼らは「UTAGEの存在に気づきにくかったけど、使い始めたら最大限活用している層」です。これが今回のターゲット(未利用×LTV高い)に最も近いプロトタイプになります。

この人たちが辿ってきた道筋(どんな状態で、何に困って、なぜ今まで気づかなかったか)を分析することで、今の未利用層の姿が見えてきます。

## 8. この層にMeta広告が効く理由

この層はGoogle検索で「MAツール 比較」を検索しません。彼らがUTAGEに出会うとしたら、それは**偶然の接触**しかありえない。その偶然を作れるのがMeta広告です。

- Instagramを夜にスクロールしている時
- Facebookで同世代の投稿を見ている時
- YouTubeで関連動画を見ている時

フィードの中に、彼らが毎日感じているけど言語化できていない痛みが言葉として流れてくる。「あ、自分のことだ」と止まる。そこから長尺のVSLを見始める。最後まで見切る(なぜなら自分の話だから)。14日トライアルを試す。使ってみて「戻れない」状態になる。

## 9. VSL訴求の4ステップ

「あ、いいかも客」は切迫していないので、**こちら側から軽く切迫させてから解決策を出す**構造が必要です。

### Step 1: 常識の宣告
**「今のやり方は間違いです」と断言する**

ターゲットが「これが普通だ」と思ってやっていることを、冒頭で否定する。
「これ以上、売れる導線を作ろうとしないでください」のような形。

### Step 2: 気づきの注入
**言語化していない違和感を突きつける**

「薄々感じていたけど言葉にしていなかったこと」を、こちらから言語化してあげる。
バラバラの手作業が脳のリソースを削り続けている構造の暴露、など。

### Step 3: 解決策の提示
**既に存在する仕組みを見せる**

「あなたが作らなくても、既に完成された仕組みがある」という事実を提示する。
UTAGEの紹介、事例、機能紹介へと進む。

### Step 4: 即行動
**リスクゼロで試せる状態を用意しておく**

14日間無料トライアルへの直接申込で着地。迷う時間を作らない。

### 各ステップの目的と具体対応

| ステップ | 目的 | UTAGE版での具体対応 |
|---|---|---|
| Step 1: 常識の宣告 | 「これやってます」を自覚させ「でも違うのか」と揺らす | 「導線を作ろうとしないでください」と断言する |
| Step 2: 気づきの注入 | 薄々感じていた違和感の正体をこちらから言語化 | バラバラの手作業が脳を削っている構造を暴露 |
| Step 3: 解決策の提示 | 既に解決された世界があることを事実として提示 | 1つにまとまった仕組みが既にある事実 |
| Step 4: 即行動 | リスクゼロで試せる状態を用意 | 14日間無料トライアルへの直接申込 |

## 10. 訴求設計の原則チェックリスト

この層に対するVSL設計で守るべき原則:

### ✓ 原則1:業態を絞る
「全事業者向け」ではなく「コンテンツビジネス1人経営者」に絞る。言葉の解像度が上がる。「誰でもOK」は誰にも選ばれない。

### ✓ 原則2:経済力のあるターゲットを明示する
「売上が既に立っている事業者向け」と早めに言う(商品がない層の解約を防ぐ)。払える層と払えない層を見極め、払える層にフォーカスする。

### ✓ 原則3:現在ではなく理想を見せる
ターゲットの現在の姿(忙しくて疲弊している)だけではなく、理想の姿(自分が休んでも事業が回る、本業に集中できる、時間のある経営者)への道筋を描く。疲弊の描写だけでは動かない。

### ✓ 原則4:情報環境に合わせて言葉を選ぶ
ターゲットは情報強者ではないため、「ファネル」「ステップ配信」「CVR」「ROAS」などの専門用語は通じない前提で設計する。言い換え or 補足説明を入れる。

### ✓ 原則5:チャネルの思い込みを捨てる
「Meta広告には良い客がいない」という先入観を持たない。ターゲットが「検索で比較検討しない」層なら、Meta広告の偶然接触こそが最適。

### ✓ 原則6:本気度のフィルタを設計する
トライアル申込後も、スタートアップガイド、オンライン作業会、勉強会などでフィルタリングし、本気で使う人だけが残る設計にする。オファー部分に「14日間で何をすべきか」の具体指示を入れる。

### ✓ 原則7:ネガティブな未来も描く
「◯◯をやっている人は、この先も変わりません」という形で、行動しなかった場合の未来も描写する。ターゲットが「自分はこうなりたくない」と気づく構造。

### ✓ 原則8:慢性化している人向けの言葉を避ける
「何度もツールを変えてきた」「色々試したけどダメだった」系のフレーズは、既に失敗経験を重ねた**ジプシー層**を呼び寄せる言葉。今回のターゲットである「違和感を感じ始めたばかりの初期段階の人」とは真逆の層を引き寄せてしまう。代わりに「感じ始めていませんか?」「思うことはありませんか?」のような**初期の違和感に呼びかける言葉**を使う。

## 11. VSL制作時のトーン指針

「あ、いいかも客」を取りに行くVSLには構造的な難しさがあります。**気づき型の訴求、感情に訴えるストーリー、明確なCTAといった要素は必要だが、それを使うと"情報商材的"に見えやすい**という点です。

この章では、売れる訴求要素は維持しつつ、過度な"情報商材臭"を排除するためのトーン指針を整理します。

### 大前提:「情報商材っぽさ」を分解する

「情報商材っぽい」という言葉の中には、実は**必須要素**と**排除可能な要素**が混ざっています。分解すると:

**売れるVSLに必須の要素(使う)**
- 気づきを与えるストーリー構成
- 感情に訴える言葉選び
- ターゲットの日常の具体描写
- 「今動かない未来」の描写
- 明確なCTA
- 行動を促す流れ

**"情報商材臭"を生む要素(排除する)**
- 誇大な成功事例の羅列(「月収1000万!」系)
- 時間制限型の煽り(「今すぐ!」「残り3名!」「24時間限定!」系)
- 胡散臭いビフォーアフター写真
- 「◯◯するだけで」系の安易な訴求
- 過度な個人崇拝(「◯◯先生に救われました」系)
- 「限定価格!」系の値引き煽り
- 誇大広告
- 過度に強いセールストーン

この分解ができれば、**売れる訴求は維持しつつ、情報商材臭は消せる**。

### 守るべきトーン3原則

#### 原則1: 「隣の分野からのお知らせ」トーン
- 上から目線の教化ではなく、同じ目線で話す
- 「知らないのは当然、別の分野だから」という前提
- 情報は提供するが、決断は相手に委ねる
- 専門家としての威厳を出しすぎない
- ターゲットの本業のプロ性を尊重する

#### 原則2: 誠実さを前面に出す
- 誇大広告をしない
- 数字は事実のみを使う(盛らない)
- 「全ての人が成功する」とは言わない
- リスクや制約も正直に伝える
- 技術的な背景や真面目さを隠さず、むしろ強みとして打ち出す

#### 原則3: 決断を相手に委ねる
- 煽らない
- 「今すぐ決めろ」とは言わない
- 「考える時間を取ってください」と言える余裕を持つ
- 相手の判断を尊重する姿勢
- ただし「今動かない未来」の描写は行う(これは事実の提示であって煽りではない)

### 使って良い要素 / 使わない要素の対応表

| 要素 | 使う/使わない | 理由 |
|---|---|---|
| 気づきを与えるストーリー | 使う | 売れる訴求の核 |
| 感情に訴える言葉 | 使う | 共感の入口 |
| ターゲットの日常描写 | 使う | 「自分のことだ」と思わせる |
| 「今動かない未来」の描写 | 使う | 内発的な緊急性の喚起 |
| 明確なCTA | 使う | 行動を促すのに必須 |
| 誇大な成功事例 | 使わない | 情報商材臭の最大原因 |
| 時間制限型の煽り | 使わない | 外発的な煽りで警戒される |
| ビフォーアフター写真 | 使わない | 胡散臭さの典型 |
| 「◯◯するだけで」系 | 使わない | 安易訴求の象徴 |
| 過度な個人崇拝 | 使わない | 宗教色が出る |
| 「限定価格!」系煽り | 使わない | 値引き依存は信頼を損なう |

### 「真面目さ」を逆手に取る差別化

情報商材業界では**信頼されるブランドが希少**です。だから「真面目さ」「技術力」「誠実さ」は実は差別化要素になります。

例えばこんな打ち出し方が可能:

- 「誇大広告をしない代わりに、本当に使える機能だけを揃えました」
- 「派手な売り方はしませんが、使っている人はずっと使い続けています」
- 「エンジニアが本気で作った、マーケティング自動化ツールです」

この方向性なら、情報商材的な訴求に飲み込まれずに、独自のポジションを築けます。

### トーン指針の実務への落とし込み

VSL制作時にチェックすべきポイント:

1. **書いた原稿を読み返して、「これ情報商材っぽいな」と感じる箇所はないか?**
2. **ある場合、それは上記の「使わない要素」に該当しているか?**
3. **該当していれば削除 or 書き換え**
4. **該当していないけど違和感があれば、トーンの問題(上から目線、威圧感、煽り)を疑う**
5. **「隣の分野からのお知らせ」トーンで書き直せないか試す**

## 備考:ターゲット選定のキーインサイト

> 「悩みが深い人は、広告では取れない」
>
> 悩みが深い人は慢性化しており、過去の失敗経験から慎重になっている。
> だから比較検討に入る。広告で取るべきは、問題がまだ慢性化する前の初期段階、
> 違和感を感じ始めたばかりで、切迫していないが経済力があり、
> 偶然の接触で「あ、いいかも」と軽く動く層である。
>
> **広告ターゲットには"旬"がある。旬を逃した人は、どれだけ悩みが深くても取れない。**

この逆説こそが、今回のVSL設計の根幹にある考え方です。

================================================
 mp4スライド → PDF 変換ツール  つかいかた
================================================

【できること】
 動画(mp4)の中でスライドが切り替わった場面を1枚ずつ画像にして、
 まとめて1つのPDFにします。参考スライドのデザイン集として使えます。


【使い方（かんたん）】
 1. 変換したい mp4 ファイルを、
    「slides2pdf.bat」のアイコンの上にドラッグ＆ドロップする。
    （複数の動画をまとめてドロップしてもOK）

 2. 黒いウィンドウが開いて処理が始まります。
    1時間くらいの動画でも数分で終わります。

 3. 終わると、元の動画と同じフォルダに
    「（動画名）_slides.pdf」ができています。


【初回だけ必要な準備】
 このツールは Python と ffmpeg を使います。
 ・Python が無い場合 … 画面の案内に従って python.org から入れてください。
                        （インストール時「Add Python to PATH」に必ずチェック）
 ・ffmpeg が無い場合 … bat が自動でインストールを試みます。
                        終わったら案内どおり、もう一度ドロップしてください。


【うまくスライドが取れないとき】
 動画によってはスライドが多すぎたり少なすぎたりすることがあります。
 その場合は、詳しい人にコマンドでの調整（--threshold）を頼んでください。

 ・お試し（先頭2分だけ処理して様子を見る）:
     python slides2pdf.py 動画.mp4 --duration 120

 ・検出のしきい値を確認する:
     python slides2pdf.py 動画.mp4 --scan

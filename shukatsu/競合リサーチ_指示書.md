# 競合リサーチ指示書（Chrome拡張のClaude向け）

このドキュメントをそのままChrome拡張のClaude（または別セッションのClaude）に
渡してリサーチを依頼してください。指示書は自己完結する形で書いてあります。

## あなたへの依頼（リサーチ実行Claudeへ）

あなたには、日本のD2Cペットフード市場における**競合分析（3C/4P）**と
**ベンチマーキング**と**施策提案**を行ってもらいます。

### 背景・目的

- 依頼者は **犬猫生活株式会社**（東証グロース上場、2026/4 IPO、証券コード556A）
  のマーケティング職に応募予定です
- 求人内容：新規顧客獲得を中心としたインハウスマーケティング
  （Meta/Google/Yahoo! 広告、LPO、N1分析、CRM、ブランド戦略）
- 直近の面接で「課題面接」（マーケ執行役員＋部長＋マネージャー）があり、
  競合理解と施策提案力が問われる前提
- 依頼者の経歴：個人事業7年でDRMをワンオペで運用してきた経験あり。
  現在は別のSaaS案件で長期LTV型サブスクのマーケを担当中

### このリサーチの最終的な使い方（重要）

依頼者は本リサーチを以下の目的で使います。設計の指針にしてください。

1. **応募書類（志望動機・職務内容）の精度向上**
2. **課題面接で「成長戦略の提案」を答える材料**
3. **入社後にマーケ部長／代表から「競合どう見てる？」と聞かれたときに
   即答できる頭の整理**

「広く浅く」ではなく、**「経営観点で本当に注視すべき相手を深く、
判断ロジック付きで」**整理してください。

### 犬猫生活の基礎情報（前提知識）

- ミッション：「すべての動物とその家族の幸せな生活のために」
- 主力商品：国産無添加プレミアムペットフード（ドライ中心、フレッシュ・サプリも展開）
- ビジネスモデル：D2C自社EC×サブスクリプション（注文の95%以上が定期購入）
- 売上：25年4月期 29億円（前期比+62%）、26年4月期予想 44.4億円
- 自社EC延べ利用者：30万人超
- 差別化軸：**利益20%を動物福祉財団に寄付**（社会貢献型ビジネス）
- 事業4軸：フード／生活産業（動物病院・トリミングサロン）／イベント／メディア
- 海外展開：2025/5 台湾でドッグフード販売開始
- バリュー：誠実であれ／チームのために動け／二兎を追い求めよ／本質に集中せよ／
  ワクワクする未来を描け
- 構造的弱点（外部指摘）：広告投資依存度の高さ、解約率の具体開示が乏しい

## リサーチ手順

### Step 1：各社の一次情報を取得

各競合について、以下の情報源を必ず確認してください：

1. **公式サイト**：商品ページ、定期購入条件、解約条件、ブランドストーリー
2. **会社情報ページ**：企業理念、沿革、規模感、財務情報（上場企業なら IR資料）
3. **最新プレスリリース**（直近1年）
4. **メディア掲載・第三者レビュー**（信頼性のあるもの）
5. **SNS公式アカウント**（X、Instagram、YouTube）：フォロワー数・クリエイティブ傾向

### Step 2：犬猫生活のIPO目論見書（有価証券届出書）を確認

これは**最強の一次情報**です：

- 犬猫生活が公式に「リスク要因」として挙げている競合の整理
- 同社が事業計画で言及している競合・市場構造
- EDINET（金融庁の電子開示システム）または同社IR・各種報道から取得可能
- 取得・確認できた範囲で本文に反映してください

### Step 3：各社を以下の項目で整理

#### 基礎情報
- 会社名、設立年、本社所在地
- 売上規模、従業員数（公開情報のみ）
- ブランドメッセージ／ミッション
- ターゲット顧客像

#### 4P分析
| 項目 | 取得すべき情報 |
|---|---|
| **Product** | 主力商品、商品ラインナップ、原材料・製法、機能性、保証 |
| **Price** | 主力商品の単価（kg単価・1食単価）、初回価格、定期割引率 |
| **Place** | 販売チャネル（自社EC／Amazon／楽天／実店舗／量販／動物病院） |
| **Promotion** | 広告クリエイティブ傾向、訴求コピー、SNSフォロワー数、UGC施策、インフルエンサー活用 |

#### 顧客接点・継続施策
- 定期購入の解約条件（縛りあり／なし）
- カスタマーサポート体制
- 同梱物・オンボーディング体験
- アップセル・クロスセル設計
- コミュニティ・イベント施策

### Step 4：3C分析を作成

#### Customer（市場・顧客）
- 日本のペットフード市場規模・成長率（2025〜2030の予測）
- D2C/プレミアム化のトレンド
- ターゲット顧客の意思決定要因（価格／健康／無添加／ブランド／社会貢献／鮮度）
- 「ペットの家族化」進行度
- チャネル別シェアの推移（量販／EC／動物病院／専門店）

#### Competitor（競合）
- 上記7社をマップ化
- ポジショニングマップ（軸：価格 × 鮮度／国産 × 機能性 など複数軸で）
- 各社の強み・弱み
- マクロ3トピックの示唆を統合

#### Company（犬猫生活）
- 犬猫生活の独自性をCompetitorとの対比で明確化
- SWOT形式での整理
- 「**犬猫生活が本当に脅威と考えるべき競合は誰か**」の判断ロジック

### Step 5：ベンチマーキング表

7社＋犬猫生活を**横並びの比較表**で作成。以下の列を含めてください：

| 項目 |
|---|
| 主力商品形態（ドライ／フレッシュ／ウェット） |
| 主力商品の月額目安（中型犬想定で統一） |
| 初回価格／割引率 |
| サブスク有無・縛り条件 |
| 解約条件（最短何回受取／いつでもOK等） |
| 国産／海外 |
| 無添加訴求の度合い |
| 獣医師・栄養士監修の有無 |
| 動物福祉・社会貢献への取り組み |
| 販売チャネル（複数選択） |
| 主要広告媒体 |
| **Instagramフォロワー数** |
| **Xフォロワー数** |
| **YouTube登録者数（あれば）** |
| 創業年 |
| 推定売上規模 |

### Step 6：犬猫生活への施策提案（10〜15個）

リサーチ結果を踏まえて、具体施策を提示してください。

#### 新規獲得（広告・LP）
- どんなクリエイティブが効きそうか
- LPの改善仮説
- 媒体配分の仮説

#### 継続率改善（CRM・チャーン）
- オンボーディング設計
- ロイヤルティ施策
- 解約抑止の構造的アイデア

#### アップセル・クロスセル
- フード→サプリ→おやつ→医療→サロンの動線
- 病院・サロン事業との連携

#### ブランド・社会貢献訴求
- 利益20%寄付をどう「買う理由」に転換するか
- UGC・コミュニティ施策

各施策に **「なぜ（根拠）」「期待効果」「実装難度（低/中/高）」** を添えてください。
抽象論ではなく、**面接でそのまま話せる粒度**で。

### ルール

- **一次情報を優先**（公式サイト・IR資料・プレスリリース・目論見書）
- **推測と事実を明確に分ける**（「事実：〜」「推測：〜」と書き分け）
- **数値は出典・取得日を明記**
- **取得できなかった情報は「データ取得不可」と明記**（捏造しない）
- **最新情報を優先**（2025〜2026年の情報を中心に）
- **判断ロジックを示す**（「なぜそう考えたか」を必ず添える）
- 文字数目安：全体で 10,000〜18,000文字程度

### 納品

- マークダウン形式でテキスト出力してください
- 表は適切に整形してください

## 補足：「面接でそのまま話せる粒度」とは

依頼者は応募準備の最中で、このリサーチをもとに以下を進めます：

1. 応募フォームの志望動機・職務内容の精度向上
2. 課題面接での「成長戦略の提案」回答の準備
3. 各面接フェーズ（一次マーケ執行役員、二次部長、課題面接、代表面接）の想定質問対策

**「面接でそのまま話せる粒度」**とは：

- 抽象論（例：「CRMを強化すべき」）ではなく
- 具体策（例：「初回購入後7日以内に獣医師監修コラム＋
  保護犬猫レポートを同送する。狙いはチャーン低減＋
  社会貢献ブランドの再認知。実装難度は中。
  既存メール基盤で実行可能」）

この粒度でお願いします。

リサーチが完了したら、本文＋出典リストを返してください。

## リサーチ手順

### Step 1：各社の一次情報を取得

各競合について、以下の情報源を必ず確認してください：

1. **公式サイト**：商品ページ、定期購入条件、解約条件、ブランドストーリー
2. **会社情報ページ**：企業理念、沿革、規模感、財務情報（上場企業なら IR資料）
3. **最新プレスリリース**（直近1年）
4. **メディア掲載・第三者レビュー**（信頼性のあるもの）
5. **SNS公式アカウント**（X、Instagram、YouTube）でクリエイティブ傾向を観察

### Step 2：各社を以下の項目で整理

各社について最低限以下のデータを取得：

#### 基礎情報
- 会社名、設立年、本社所在地
- 売上規模、従業員数（公開情報のみ）
- ブランドメッセージ／ミッション
- ターゲット顧客像

#### 4P分析
| 項目 | 取得すべき情報 |
|---|---|
| **Product** | 主力商品、商品ラインナップ、原材料・製法、機能性、保証 |
| **Price** | 主力商品の単価（kg単価・1食単価）、初回価格、定期割引率 |
| **Place** | 販売チャネル（自社EC／Amazon／楽天／実店舗／量販／動物病院） |
| **Promotion** | 広告クリエイティブ傾向、訴求コピー、SNSフォロワー数、UGC施策、インフルエンサー活用 |

#### 顧客接点・継続施策
- 定期購入の解約条件（縛りあり／なし）
- カスタマーサポート体制
- 同梱物・オンボーディング体験
- アップセル・クロスセル設計
- コミュニティ・イベント施策

### Step 3：3C分析を作成

#### Customer（市場・顧客）
- 日本のペットフード市場規模・成長率（2025〜2030の予測）
- D2C/プレミアム化のトレンド
- ターゲット顧客の意思決定要因（価格／健康／無添加／ブランド／社会貢献／鮮度）
- 「ペットの家族化」進行度

#### Competitor（競合）
- 上記10社をマップ化
- ポジショニングマップ（軸：価格 × 鮮度／国産 × 機能性 など複数軸）
- 各社の強み・弱み

#### Company（犬猫生活）
- 犬猫生活の独自性をCompetitorとの対比で明確化
- 強み・弱み・機会・脅威（SWOT形式でも可）

### Step 4：ベンチマーキング表

10社＋犬猫生活を**横並びの比較表**で作成。以下の列を含めてください：

| 項目 |
|---|
| 主力商品形態（ドライ／フレッシュ／ウェット） |
| 主力商品の月額目安（中型犬想定で統一） |
| 初回価格／割引率 |
| サブスク有無・縛り条件 |
| 国産／海外 |
| 無添加訴求の度合い |
| 獣医師・栄養士監修の有無 |
| 動物福祉・社会貢献への取り組み |
| 販売チャネル（複数選択） |
| 主要広告媒体 |
| SNSフォロワー数（Instagram主） |
| 創業年 |
| 推定売上規模 |

### Step 5：犬猫生活への施策提案

リサーチ結果を踏まえて、以下の観点で**施策案を10〜15個**提示してください：

#### 新規獲得（広告・LP）
- どんなクリエイティブが効きそうか
- LPの改善仮説
- 媒体配分の仮説

#### 継続率改善（CRM・チャーン）
- オンボーディング設計
- ロイヤルティ施策
- 解約抑止の構造的アイデア

#### アップセル・クロスセル
- フード→サプリ→おやつ→医療→サロンの動線
- 病院・サロン事業との連携

#### ブランド・社会貢献訴求
- 利益20%寄付をどう「買う理由」に転換するか
- UGC・コミュニティ施策

各施策に **「なぜ」「期待効果」「実装難度」** を添えてください。

## アウトプット形式

### 1. 全体構成（マークダウン1ファイルにまとめる）

```
# 犬猫生活 競合分析レポート

## エグゼクティブサマリー（A4半ページ程度）

## 1. 市場概観（Customer分析）

## 2. 競合10社の個別プロファイル
### 2.1 PETOKOTO FOODS
### 2.2 ココグルメ
...
### 2.10 ロイヤルカナン

## 3. ベンチマーキング表（横並び比較）

## 4. ポジショニングマップ（テキストで表現）

## 5. 犬猫生活の独自性と機会（3C統合）

## 6. 施策提案（10〜15個）

## 7. 出典一覧（URL明記）
```

### 2. ルール

- **一次情報を優先**（公式サイト・IR資料・プレスリリース）
- **推測と事実を明確に分ける**（「事実：〜」「推測：〜」と書き分け）
- **数値は出典・取得日を明記**
- **取得できなかった情報は「データ取得不可」と明記**（捏造しない）
- **最新情報を優先**（2025〜2026年の情報を中心に）
- 文字数目安：全体で 8,000〜15,000文字程度

### 3. 納品

- マークダウン形式でテキスト出力してください
- 表は適切に整形してください
- URLは markdown のリンク形式 `[タイトル](URL)` で

## 補足

依頼者は応募準備の最中で、このリサーチをもとに以下を進めます：

1. 応募フォームの志望動機・職務内容の精度向上
2. 課題面接での「成長戦略の提案」回答の準備
3. 各面接フェーズ（一次マーケ執行役員、二次部長、課題面接、代表面接）の想定質問対策

そのため、**「面接でそのまま話せる粒度」**で施策提案を書いてもらえると最も助かります。
抽象論ではなく、具体的な実装イメージまで落とし込んでください。

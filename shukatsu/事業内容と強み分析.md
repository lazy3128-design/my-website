#### DRMファネル構造（業界標準）

```
Meta広告 → LP（リスト取り用） → オプトイン（CV）
       → ウェビナー / 動画 / ステップメール・LINE 教育
       → 14日トライアル申込
       → 本契約／継続
```

- リスト→本契約の成約率相場：**3〜8%**
- 高単価（50万円〜）でないとCAC回収が構造的に厳しい

#### ファウンテンの構造の正確な理解

- ファウンテンは5年来、UTAGEを月21,670円で売り続けている**長期LTV型サブスクSaaS事業者**
- 設立当初（5年前）から使い続けるロイヤル顧客が多数（最長5年、続けば10年も）
- 元々の獲得チャネル：Xインフルエンサー紹介、SEO、口コミ、紹介
- 広告経由獲得は teru 参画前ゼロ → teru が立ち上げ中
- 「DRM→長期LTV型への転換」ではない。**会社は最初から長期LTV型**

#### この経験から語れる学び

- 7年DRM経験のメインは**高単価商材**（クライアントの成果が出やすいから）
- ファウンテンで初めて**低単価×長期LTV型サブスク**の自社販売マーケに挑戦中
- 高単価DRMと長期LTV型サブスクの両方の設計思想を理解しつつある
- 犬猫生活（プレミアム価格×長期サブスク×ロイヤル顧客連鎖）と
  非常に近い構造の経験を、今まさに積んでいる

#### オンボーディング改善＝チャーン下げの実体験

- ファウンテン案件で解約率改善のためのオンボーディング提案を実施
- 1ヶ月で少しずつ下がっている兆候
- → 犬猫生活のチャーン改善課題と直結する経験

→ 登録CV/CVR/CPA → 申込CV/CVR/CPO

→ 完成形のWebセミナー型DRMファネル設計。

### 15. 当社を志望する動機（必須）★最重要

```
3つの理由から犬猫生活様を志望しております。

【1. 「ビジネスは社会課題を解決するための手段」という代表佐藤様の信念への共感】
個人事業として10年間マーケティングを生業にしてきたなかで、「自分が販売する商品の社会的意義」を考える機会が増えました。
直近では自身のメイン事業を一度畳む経験もあり、「次は本気で誇れる商品の事業に関わりたい」という想いが強くなりました。
代表のインタビューで「ビジネスは、社会課題を解決するための手段である」という言葉に出会ったとき、自分のマーケティング観と完全に重なりました。

【2. 「利益20%を動物福祉財団に寄付」という事業設計の唯一性】
競合のPETOKOTOは売上の1.2%、ココグルメはSDGs取り組みレベルにとどまり、「利益から固定比率」で寄付している同価格帯のD2Cは犬猫生活様だけです。
これは経営の意思決定そのものを差別化に組み込んでおり、最強の「買う理由」になっていると考えます。
私はDRMで「顧客が買う理由」をずっと設計してきた立場として、この差別化を最大化する施策（LP改修・オンボーディング・CRM）に貢献できると考えています。

【3. 自身の経験と御社のフェーズが噛み合うこと】
直近では業務委託で低単価サブスクSaaS事業のマーケティングを担当しており、「広告から獲得→オンボーディングで継続率改善→LTV最大化」というサイクルを実務で運用しています。
御社は上場直後で、IPO調達金を全額広告宣伝費に投下しながらLTV/CAC 18.8倍という収益構造を維持していくフェーズと理解しております。
広告比率35%は、北の達人コーポレーション37%と同水準で、単品リピートD2Cとして標準的範囲。むしろLTV/CAC 18.8倍がある以上、超効率的な投資戦略だと捉えています。本当のリスクは「広告依存度の高さ」ではなく「広告効率劣化のリスク」であり、ここをコホート別CAC/LTVダッシュボードで早期検知する仕組みづくりに、私のDRM経験＋経理素地が活かせると考えています。
私のDRM経験＋経理・財務のバックグラウンド＋ファウンテン案件での現役のサブスクマーケ経験は、このフェーズで実務として貢献できる組み合わせだと考えます。

【補足：個人的な動機】
実家で雑種の黒猫を17年間家族として飼ってきました。現在は転居の事情で飼えていませんが、今年中にペット可物件へ引っ越し、必ず猫を迎える予定です。
「うちの子が喜ぶ仕事を」というバリューが、文字通り重なる立場で働きたいと考えています。

行動指針の中では特に「二兎を追い求めよ」に強く共感しました。
事業成長と社会貢献を両立させることは、口で言うほど簡単ではありません。
私は7年DRMをやってきた中で、「売上を伸ばす」と「誇れる商品を売る」のバランスに悩んできました。
犬猫生活様はその答えを事業設計に組み込んでいる会社であり、ここで自分のマーケスキルを発揮したいと考えています。
```

→ **現場感ポイント**：
- 数字を出典付きで使う（PETOKOTO 1.2%、LTV/CAC 18.8倍）
- 自分の経験と接続して語る（DRM7年、サブスク経験）
- バリュー「二兎を追い求めよ」を自分の文脈で語る
- 黒猫17年は嘘なし・最強の個人エピソード
- 「自身のメイン事業を一度畳む経験」を正直に出す＝バリュー「誠実であれ」との整合

## 補足：書く前のチェックリスト

### 書類提出前に確認すること

- [ ] 文字数：項目14（職務内容）と項目15（志望動機）はそれぞれ800〜1500字程度に収める。長すぎると読まれない、短すぎると熱量が伝わらない
- [ ] 数字の出典が頭に入っているか（LTV/CAC 18.8倍、PETOKOTO 1.2%、ペットフード市場5,122億円など）
- [ ] バリューを言及するなら1〜2個に絞り、自分の経験と接続する
- [ ] 「自分の事業を一度畳んだ」を正直に書く（隠さない）
- [ ] 黒猫17年のエピソードを入れる
- [ ] 「うちの子を迎える予定」を入れる
- [ ] 「2026年4月IPO上場」「LTV/CAC 18.8倍」など、リサーチ感が伝わる数字を1〜2個入れる
- [ ] 「ですます調」で統一
- [ ] 誤字脱字チェック（特に「動物福祉」「殺処分」「ヒューマングレード」等）

### 書類で書かないこと（重要）

- 自己破産準備中の話
- 過去の所得（節税の話）
- 短期離職の本当の理由（髪型・先輩との衝突など）
- 「商材ヤー」「情報商材」等の業界俗語
- 「絶対に成果出します」等の根拠なき断言
- 競合の悪口・批判
- 給与希望の上限（書類段階では「想定年収400万円〜の範囲で柔軟に対応可」程度）

## 提出前の最終チェック手順

1. このドラフトをコピー
2. 自分の手で読み直して違和感のある表現を直す
3. 文字数を確認（職務内容 800〜1500字、志望動機 800〜1500字推奨）
4. 商品到着後、N1観察メモがあれば志望動機に1段落追加：

```
【商品体験から】
申込から到着まで〇日。
初回500円キャンペーンでお試しを購入し、実際に彼女の知人の犬に食べてもらいました。
（具体の反応・パッケージのコピーの感想・同梱物の体験などをここに）
顧客の立場で御社のマーケティングを体感した上で、応募させていただきます。
```

5. Googleフォームに貼り付ける（一度下書きしてからコピペ）
6. 「送信」前に一晩寝かせて読み直す

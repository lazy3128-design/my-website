## 1. SWOT統合 ― 3C "Company" を判断ロジック付きで再構成

### Strengths（強み）

- **S1：「利益20%を動物福祉財団に寄付」という、競合に絶対に真似されにくい差別化軸**
  - PETOKOTOは累計寄付18,022,321円（2026/1時点）、ココグルメはSDGs取り組みレベル
  - "利益から固定比率"で寄付している競合は同価格帯ではゼロ
  - コピー耐性が極めて高い

- **S2：LTV/CAC 18.8倍という異常値の収益性**（IPO目論見書由来、Invest Leaders経由）
  - D2Cサブスクの一般的健全値が3〜5倍といわれる中、4〜6倍水準を独走
  - 継続率95%＝5%チャーンが事実なら、構造的にこの数字は説明可能

- **S3：ドライフード×D2Cサブスクという、最も粗利・物流効率が高い構造を選択**
  - ココグルメ・PETOKOTOが主軸とするフレッシュ（冷凍）は構造コストを背負う
  - 犬猫生活はドライ主体のため、原価率・物流費・解約耐性のすべてで有利

- **S4：自社往診クリニック「犬猫生活どうぶつ往診クリニック」保有**
  - D2Cフード企業で動物病院を内製化しているのは犬猫生活だけ
  - 療法食という"医療連動・粗利の高い・チャーンしない"市場への布石
  - ロイヤルカナンの牙城を内側から突き崩しうる唯一のアセット

- **S5：会員30万人・定期会員約6万人のファーストパーティデータ資産**
  - iOS14以降のトラッキング規制下で、自社購買データの価値が指数関数的に増加
  - 「犬種×年齢×購買頻度×解約理由」の解像度が高い1stパーティデータ

- **S6：事業4軸構造（フード／生活産業／イベント／メディア）による顧客接点の多重化**
  - 単一商品依存ではなく、サロン・病院・イベント・自社メディアで顧客接点
  - マース／レティシアン／バイオフィリアいずれも持っていない「ライフスタイル全体OS」化戦略

### Weaknesses（弱み）

- **W1：広告投資への構造依存**
  - 25/4期広告宣伝費10.2億円／売上29億円＝売上の約35%が広告費（EDINET S100W3WI）
  - IPO調達金は全額を広告宣伝費に充当（27/4期5.5億・28/4期6.0億計画）
  - 広告効率が落ちた瞬間に成長が止まる脆弱な構造

- **W2：解約率の具体値非開示（IRリスク）**
  - 「継続率約95%」とは語るが、月次/コホート別の解約率データ開示なし
  - IPO後の機関投資家の最初の質問対象
  - マーケ側の最大の経営課題でもある

- **W3：オフラインチャネルの弱さ**
  - 卸取引先は大型店5社・小規模43店（目論見書）
  - ココグルメの全国2,000店舗と桁違いの差

- **W4：単一カテゴリ偏重（ドライフード）**
  - おやつ・ウェット・サプリ・グッズなどアップセル余地の活用が見えない
  - 1顧客あたり購入カテゴリ数の低さは、LTV上限を低くしている（推測）

- **W5：海外展開の実績が"足場"レベル**
  - 台湾・米国展開はあるが、売上構成比に表れるレベルではない

- **W6：ブランド認知度の競合比劣位（推測）**
  - PETOKOTOの犬向け7.6万・ココグルメ5.1万に対し、犬猫生活の犬向けは2.7万
  - 寄付20%という最強の物語が世間に届ききっていない

### Opportunities（機会）

- **O1：ロイヤルカナンの療法食EC自由販売停止（2024年10月〜）による動物病院チャネル構造変化**
  - 飼い主が「療法食をどこで買うか」が空白状態
  - 自社クリニック＋自社D2C＋自社製造を全部持っている犬猫生活は、この穴を埋められる唯一のD2C

- **O2：1頭あたり支出の継続的増加**
  - 飼育頭数は減少／横ばい（犬682万・猫884.7万、2025年）
  - 「ペットの家族化」進行で1頭あたり支出は伸び続けている

- **O3：海外展開（台湾→東南アジア）の余地**

- **O4：殺処分問題への社会的関心の継続**
  - 令和6年度殺処分6,830頭、ピーク（平成16年度39万頭）から約98%減少
  - 寄付20%との接続が極めて強い

- **O5：マイクロチップ義務化（2022年6月）以降のID連動マーケ余地**

- **O6：D2C成熟期の"ロイヤル顧客×サブスクリプション"重視への市場転換**
  - 広告高騰下では"継続率と単価"が勝ち筋に変わる
  - 犬猫生活の構造はこの転換に最も合致している

### Threats（脅威）

- **T1：ココグルメ（バイオフィリア）のドライ参入（2025年8月）** ← 最大の直接脅威
- **T2：レティシアン（オーダーチーズグループ売上123億円規模／2024年4月期）**
- **T3：ユニチャーム等の大手の本気D2C参入リスク**
- **T4：iOS14以降の広告トラッキング制限のさらなる強化と広告CAC高騰**
- **T5：海外資本（マース／ヒルズ等）の日本市場深耕シフト**
- **T6：原材料費・物流費高騰と円安の継続**

4軸でスコアリング：①直接競合度、②財務・広告物量、③参入の速さ・本気度、④犬猫生活のホームグラウンドへの侵食度

## 2. 競合選定の判断ロジック

### 選定軸

- 軸α：顧客の財布の取り合い度合い
- 軸β：チャネル競合度（D2C・EC・サブスク）
- 軸γ：参考価値（マーケ施策・LTV設計として学べる構造）
- 軸δ：構造的脅威性（5年単位）

### 含めた7社の理由

| 競合 | 含めた主たる理由 |
|---|---|
| PETOKOTO FOODS | フレッシュD2Cの直接競合・社会貢献訴求の比較対象（α・β・γ） |
| ココグルメ | 最大の直接競合・ドライ参入で本丸に侵食（α・β・δ） |
| このこのごはん | 同じ国産無添加ドライD2C・アフィリエイト戦略の参考（α・β・γ） |
| うまかドッグフード | 国産訴求・サブスク設計の参考・地方拠点の事例（γ） |
| モグワン/カナガン（レティシアン） | 業界最大の広告物量・百万会員の構造・実店舗化シフト（β・γ・δ） |
| ロイヤルカナン（マース） | 療法食EC撤退による機会の源泉・動物病院チャネルの王者（δ） |
| オリジン（Champion Petfoods） | 海外プレミアム最高位の品質訴求・並行輸入とトレーサビリティ問題（γ） |

### 外した競合の理由

| 外した競合 | 理由 |
|---|---|
| GREEN DOG | プレミアム小売（実店舗）型でD2Cサブスクではない |
| ヤラー（Yarrah） | 日本市場での存在感が薄い |
| アカナ（Acana） | オリジンと同じChampion Petfoods系列 |
| ヒルズ | 動物病院チャネルの構造はロイヤルカナンとほぼ同じ |
| ユニチャーム／ペットライン／いなば等 | 顧客が違う（軸α弱）。D2C本気参入で再評価必要（T3） |
| PE-TANTO／FUDGEE等 | スケール感小、面接で語る価値が低い |

**面接で問われたときの一行回答**：「犬猫生活の顧客を直接奪うか／犬猫生活の戦略選択に5年単位で影響するかで絞り込みました。マス流通プレイヤーは現状では財布が違うので外しましたが、ユニチャームのD2C本気参入が起きれば即座にT3として再評価する設計です」

## 3. IPO目論見書からの戦略的示唆

### 3.1 取得済み事実

- LTV/CAC：**18.8倍**（Invest Leaders経由・目論見書由来）
- 継続率：**約95%**（同上）
- 定期会員：約6万人超（2025年5月時点／バフェット・コード経由）
- 広告宣伝費：1,019,313千円＝**約10.2億円**（25/4期、EDINET S100W3WI）
- 売上：29億円（25/4期）／予想44.4億円（26/4期、+62%）
- IPO調達資金使途：全額広告宣伝費（27/4期5.5億、28/4期6.0億計画）
- 株主構成：MZファンド（前澤友作氏）等が出資。前澤44.59%、佐藤34.25-36.16%
- ロックアップ：180日（2026/10/19まで）

### 3.2 取得不可項目

- リスク項本文の詳細（バフェット・コードのリスクタブが非会員に非表示）
- 解約率の具体値（月次／コホート別）
- マーケティング部門の人員計画詳細
- 中期事業計画のKPIブレイクダウン

### 3.3 戦略的示唆

1. **LTV/CAC 18.8倍は最大の資産であり同時に最大の説明責任**
   - この数字が機関投資家に評価されたからこそIPOが成立した
   - マーケ責任者の最大KPIは「LTV/CACの維持または改善」
2. **「広告に全額投下」は両刃の剣**
   - 広告効率劣化を早期検知する仕組み（コホート別CAC/LTVダッシュボード）が必須
3. **解約率非開示はマーケ側の最大の経営アジェンダ**
   - 「面接で犬猫生活側の経営課題を語る最も鋭い切り口」
4. **前澤ファンドの存在は"覚悟"の証明**
   - 寄付20%との相性が良くブランド信頼性を強化
   - 施策設計でも「ファンド/オーナーの哲学とブランドの一貫性」が暗黙の制約

## 4. 業界全体の構造的課題と市場機会（補完7-bis）

### A. 市場の構造変化

- 犬の飼育頭数682万頭（2025年）、猫884.7万頭
- 国内ペット市場規模 約1.9兆円（2025年度・矢野経済）
- ペットフード市場予測5,122億円（2026年・富士経済）
- **「頭数取り合い」ではなく「1頭あたり財布の深掘り」が勝ち筋**

### B. 動物福祉・社会課題

- 令和6年度殺処分 犬1,964頭・猫4,866頭（合計6,830頭）
- ピーク（平成16年度39万頭）から約98%減少
- 返還・譲渡数は32,506頭で殺処分の約4.8倍
- **「殺処分減少の物語」を「次の課題への20%寄付の貢献」に再フレーミングする必要**

### C. 獣医療・健康領域

- 愛玩動物看護師法施行（2023年5月本格運用）で看護師の国家資格化
- 地方獣医療の供給不足、健診受診率の低さ、終末期医療・ペットロス対応の社会的遅れ
- **往診クリニックを内製化している唯一性は、療法食LTVと健康データという2つのアセットを生む**

### D. 業界の信頼性・規制問題

- ペットフード安全法（2009年施行）、ステマ規制（2023年10月景表法改正）
- アフィリエイト・インフルエンサーマーケが直撃
- **広告依存度の高さは弱みだが、ステマ規制でアフィリ依存競合が苦しむ局面では、正規広告×ブランド物語の犬猫生活が相対的に有利**

### E. サプライチェーン・コスト

- 原材料費・物流費・冷凍輸送コスト・円安が継続的に上昇圧力
- **ドライ主体（S3）の構造優位がコスト高騰局面で増幅**

### F. 業界のDX・マーケティング課題

- D2C全般の広告依存問題、iOS14以降のトラッキング制限、動物病院チャネルのデジタル化遅れ
- **1stパーティデータ（S5）と内製動物病院（S4）の組み合わせは、業界DX遅れの中でほぼ唯一の解**

### G. 海外・グローバル動向

- 日本品質×社会貢献の二本柱で東南アジアへ
- グローバルではオリジンに学び、アジアでは日本ブランドとして仕掛ける二段構え

## 5. 施策提案（16個）

### A. 新規獲得（広告・LP）

#### 施策1：寄付20%を主訴求にした「物語型LP」へのLPゼロベース再設計
- **なぜ**：競合のLPはすべて「成分・原材料・国産」を主訴求にしており、犬猫生活のLPは寄付20%という最強差別化が「おまけ」扱い
- **具体策**：LPファーストビューを「あなたの月◯円が、保護犬猫◯頭の◯日分のごはんになる」というインパクト訴求に差し替え。Meta広告のクリエイティブも"成分訴求"と"寄付物語訴求"のABテストを並列稼働。ターゲットは保護犬猫支援に共感する30〜50代女性飼い主、オファーは初回50%OFF＋「あなたが寄付した結果レポート」初月同梱
- **期待効果**：CVR +15〜25%、CAC -10〜15%（仮説ベース）
- **実装難度**：中
- **優先度**：S

#### 施策2：「ステマ規制下で信頼できるレビュー」をPR起点で取りに行く
- **なぜ**：レティシアンが100万会員を作った主たるエンジンはアフィリエイト・比較サイト。ステマ規制（2023年10月）で正規メディア露出を取りに行ける窓が開いている
- **具体策**：日経クロストレンド／日経MJ／PRESIDENT WOMAN／週刊東洋経済等の経済紙にIPO×社会貢献文脈で寄稿/取材露出を月1本ペースで仕掛ける。獣医・ペットロス専門家・保護団体代表との対談コンテンツをオウンドメディアで連載
- **期待効果**：指名検索 +20〜30%、CAC -5〜10%
- **実装難度**：中
- **優先度**：A

#### 施策3：「ペットの誕生日／お迎え記念日」起点のニッチターゲティング
- **なぜ**：1stパーティデータ（S5）と外部の犬種別関心データを掛け合わせれば、超精密配信ができる。広告高騰下では勝ち筋はマス配信ではなくセグメント精密化
- **具体策**：Meta／LINE広告で「子犬の最初の3ヶ月」「シニア期入り（7歳）」「お迎え記念日前後」というライフイベント起点に自動メッセージング配信
- **期待効果**：セグメント別CVR +30〜50%、CAC -15%
- **実装難度**：中
- **優先度**：A

### B. 継続率改善（CRM・チャーン）

#### 施策4：解約率コホート分析の運用化と"離脱予兆スコア"の導入
- **なぜ**：解約率非開示（W2）はIR上のリスクであると同時に、内部運用上も「離脱顧客の見える化」が不十分なはず
- **具体策**：①過去24ヶ月の購買データから「解約直前90日の購買パターン」を機械学習で抽出。②離脱予兆スコアが閾値超えた顧客に対し、自動でクーポン／カスタマーサクセス架電／量変更提案を実施。③月次でコホート別解約率を経営会議でレビュー
- **期待効果**：年間解約率 -1.5〜3pt（継続率95%→96.5〜98%）、LTV +15〜30%
- **実装難度**：中
- **優先度**：S

#### 施策5：「ごはん量自動調整」フィードバックループ機能
- **なぜ**：D2Cフード解約理由の上位は「余る／足りない」のサイクル不一致
- **具体策**：マイページ／LINE公式で「最近食事量はどうですか？」を月1回プッシュ。回答に応じて次回配送量を自動調整。体重入力フォーム連動で「適正量」をAI提案
- **期待効果**：「量が合わない」起因の解約 -50%、年間解約率 -1pt以上
- **実装難度**：低
- **優先度**：S

#### 施策6：「卒業お迎え式」とペットロス対応CRMフロー
- **なぜ**：犬猫の高齢化に伴い、「ペットの死による解約」が今後5〜10年で構造的に増える。ミッションを掲げる以上、ペットロス対応こそが最強のブランド体験になる
- **具体策**：解約理由「ペットが亡くなった」を選択した顧客に、送付物として手紙＋しおり＋寄付実績書を物理で送る。後日「次のお迎え」検討時に再アクティベーション
- **期待効果**：ペットロス起因の解約フローの質的向上、ブランドNPS向上
- **実装難度**：中
- **優先度**：A

#### 施策7：「うちの子カルテ」自動生成（往診クリニック連携の前段）
- **なぜ**：1stパーティデータ（S5）と自社往診クリニック（S4）を保有していながら、両者がデータ統合されていない（推測）
- **具体策**：マイページに「うちの子カルテ」セクションを新設。購買履歴、体重・うんち状態・元気度、（オプトインで）往診クリニック受診記録を一画面に統合

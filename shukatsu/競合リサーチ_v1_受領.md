# 犬猫生活 競合分析レポート
作成日：2026年5月25日 / すべての出典URLは末尾「10. 出典一覧」に集約／取得不可情報は「データ取得不可」と明記

エグゼクティブサマリー

犬猫生活（東証グロース 556A）は、**「国産無添加ドライ×D2Cサブスク×利益20%動物福祉寄付」**という三位一体のポジションで、26年4月期売上44億円（前期比+53%）を狙う成長企業です。リサーチを通じて見えてきた構造は以下のとおりです。

結論として覚えて帰るべき5点：

本当に脅威と考えるべき競合は2社に絞られる。ひとつは バイオフィリア（ココグルメ）——年商20億円超・リピート率95%・累計販売施設2,000店超・累計犬猫会員40万頭・2025年8月にドライフード参入と、犬猫生活の「ドライ×D2C×社会貢献」コア領域を真正面から侵食してくる存在。もうひとつは レティシアン（モグワン／カナガン）——売上78億円規模（2017年9月期）・広告出稿の絶対量・価格帯近接の脅威。

「フレッシュ」勢（PETOKOTO・ココグルメ）が次の主戦場になる。犬猫生活はドライ中心だが、PETOKOTOは5,000万食、ココグルメは販売施設2,000店という規模感に達しており、「鮮度」軸の認知優位を握られている。犬猫生活が手作りごはん／フラットで参戦しているのは、この防衛戦の表れ。

動物病院チャネルは2024年10月以降、構造変化。ロイヤルカナンの療法食がEC自由販売を停止し、病院チャネルへの再囲い込みが進行。犬猫生活が「自社往診クリニック」を持つことは、療法食という最も粗利が高い領域への布石として極めて合理的。

国内大手（ユニチャーム）の脅威は中期で顕在化。ユニチャームはペットケア事業売上1,561億円規模（2025年）でブラジル参入など本気度が高く、いずれ国内プレミアム×D2Cにも資本投下する可能性。ただし「動物福祉×ブランド純度」では犬猫生活が優位。

犬猫生活の構造的弱点は「広告依存」と「解約率の非開示」。目論見書でも解約率が開示されておらず、上場後の最大の改善KPIになる。施策提案は新規獲得（広告/LP）よりも**継続率改善（CRM/同梱物/コミュニティ）とLTV拡張（病院・サロン・サプリへの動線）**に重心を置くべき。

面接で問われた際は、「PETOKOTOやココグルメと真正面から殴り合うのではなく、ドライの携帯性・保存性・価格安定という"日常使い"の強みと、**動物福祉20%寄付という"買う理由"**を、CRM起点で組み合わせる勝ち筋」と答えるのが筋が良いと考えます。

事実：飼育頭数は微減〜横ばいだが、「1頭あたり支出」が伸びる構造に転換。プレミアム・無添加・国産・ヒューマングレード訴求の商品群が市場を牽引。

顧客の意思決定要因（推測：複数の競合公式メッセージから抽出）

「ペットの家族化」を背景に、購入意思決定は次の優先順位で動いていると推測されます：

1. 健康（食いつき・体調変化の実感）——ココグルメのVoiceに「涙やけが減った」「体重が増えた」など"症状改善"型UGCが大量に蓄積。これが最強の獲得チャネル。
2. 安全（無添加・国産・ヒューマングレード）——どの競合も第一訴求として横並びでこれを使っており、もはや差別化要素ではなく「テーブルステークス」。
3. 食いつき——「フードジプシー」の解決ニーズが極めて強い（ココグルメUGCが象徴的）。
4. 獣医師／栄養士監修——信頼担保。
5. 価格／継続コスト——プレミアム帯の中で月1万円前後に落ち着く必要。
6. 社会貢献／物語——犬猫生活の「利益20%寄付」、PETOKOTOの「売上1%」、ココグルメの「殺処分ゼロ／SDGs」と、各社揃って訴求。ここで横並びになっている点は、犬猫生活の差別化を弱める要因。

チャネル構造の推測

- 量販／GMS：ロイヤルカナン、ユニチャーム、ペットライン、日清ペットフードの主戦場。
- 動物病院：ロイヤルカナン／ヒルズが支配。2024年10月のEC自由販売停止で病院チャネル囲い込みがさらに強化。
- EC（自社）：犬猫生活、PETOKOTO、ココグルメ、レティシアン勢の主戦場。
- EC（モール）：レティシアンが楽天・Amazonでも強い。犬猫生活も楽天・Yahoo・Amazonに出店あり。
- 専門店／量販拡張：ココグルメが2,000店、PETOKOTOがGREEN DOG・グランドフードホール・PETEMO・ライフなどに展開。犬猫生活はオフライン弱い。

## 3. マクロ3トピック

### 3.1 国内大手メーカーのプレミアムD2C参入動向

- ユニチャーム（ペットケア事業売上1,561億円／2025年）：2025年12月期、北米ペットケア事業と中東・エジプトの好調を背景に売上+3.7%・コア営業利益+9.6%。2026年5月、ブラジルでペットケア事業に参入（Nutrire社）
- 示唆：ユニチャームの本気投資先はまだ海外重心。ただし国内D2Cプレミアムへの本格参入が始まれば、資本力・ブランド・流通の総合力で最大の脅威
- 日清ペットフード／ペットライン：プレミアムD2C参入動向はデータ取得不可

### 3.2 動物病院チャネルの構造（最重要トピック）

- **事実：2024年10月から、ロイヤルカナンの療法食はインターネット上で自由に販売・購入ができなくなった**
- 構造的に重要：療法食はペットフードの中で最も粗利率・継続率が高いカテゴリ
- 犬猫生活が自社往診クリニック・地方ペットクリニックを保有することの戦略的意味は、「フード→疾患診断→療法食処方→継続購入」というLTV最大化動線を自社内で完結できる点

### 3.3 海外プレミアム勢の日本市場戦略

- オリジン／アカナ：Champion Petfoods。日本では正規代理店経由と並行輸入が並存。円安で価格上昇圧力
- ヤラー：日本市場での存在感薄く脚注扱い
- 円安局面の含意：国産プレミアム（犬猫生活、このこのごはん、うまか）に追い風
